## Overview

Design review shouldn't happen only at the end. Plan review checkpoints throughout development to catch issues early.

## Review Plan

```markdown
### Pre-Implementation Review
- Are design specs complete and unambiguous?

### Mid-Implementation Review
- Does the core layout match the design?
- Are design tokens being used correctly?

### Final Review
- Full visual QA pass
- Responsive behavior verification
- Accessibility check
```

## Rules

- Review early, review often — fixing a layout issue at the end is 10x more expensive
- Each checkpoint should have specific criteria, not "looks good"
