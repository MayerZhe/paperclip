## Overview

Brand guidelines ensure visual consistency. Every element should feel like it belongs to the same brand. Apply brand rules, don't invent new ones.

## Brand Elements

- **Logo**: placement, clear space, minimum size, variants (light/dark)
- **Colors**: primary palette, accent colors, usage ratios, accessibility contrast
- **Typography**: brand typefaces, fallbacks, usage hierarchy
- **Imagery**: photo style, illustration style, icon set
- **Tone of Voice**: brand personality in copy

## Rules

- Use exact brand color values — don't approximate
- Maintain minimum clear space around logo
- Never stretch, rotate, or recolor the logo
- Brand typography takes precedence over personal preference
- When in doubt, reference the brand guide, not your memory
